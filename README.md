# SimpleInventoryStacking

A Planet Crafter mod that adds item stacking for plater inventory, chests and some extractors.

## Installation

1. Download SimpleStacking.dll from the Releases section
2. Copy the file to the BepInEx/plugins/ folder in the game
3. Launch the game

## Requirements

- BepInEx installed
- Planet Crafter (current version)

## Building from source (for developers)

1. Install the .NET SDK
2. Copy the dependency DLLs to the libs/ folder (listed in .csproj)
3. Run dotnet build -c Release
